# CAREER COMPASS: IT CAREER DASHBOARD

An interactive IT career guidance dashboard built using Python and Streamlit to help students and career seekers explore different IT career opportunities.

## 📌 Project Overview

**CAREER COMPASS: IT CAREER DASHBOARD** is a mini project developed during my **Summer Internship at NIELIT Guwahati Centre** in the domain of **Artificial Intelligence & Machine Learning (AI/ML) using Python**.

The dashboard provides career-related information in an interactive and user-friendly format, helping users explore different IT career paths based on skills, salary expectations, demand, growth potential, top locations, and career roadmaps.

## 🚀 Features

- Explore different IT career options
- View required skills for each career
- View starting salary and salary after 5 years
- View career demand level
- View career growth potential
- Explore top locations for different career opportunities
- View career roadmaps
- Interactive and user-friendly Streamlit interface
- Data-driven career exploration

▶️ How to Run
1. Clone the Repository
git clone https://github.com/Sabdarr/career-compass-it-career-dashboard.git
2. Navigate to the Project Folder
cd career-compass-it-career-dashboard
3. Install Required Libraries
pip install streamlit pandas openpyxl
4. Run the Streamlit Application
streamlit run main.py

The dashboard will open in your web browser.
